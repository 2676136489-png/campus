# 项目路线图

## 已完成

- 实名认证与管理员审核闭环
- 动态广场、点赞、评论、关注、私信、通知
- 动态收藏与我的收藏页
- 话题标签与自动筛选
- 动态草稿自动保存与恢复
- 评论回复与回复通知
- 登录邮箱验证码二步验证（SMTP 三通道），验证过一次的设备 30 天免验证码
- AI 助手：Dify Agent 流式对接，回答中的同学/动态实体渲染为可点击跳转卡片
- AI 助手双会话：学生会话与管理员会话走独立应用与密钥，学生端与后台导航分别渲染
- 管理员权限分级与敏感入口控制
- 管理员账号管理与审计
- 管理员操作回滚与审计恢复
- 举报治理、敏感词过滤、拉黑、隐私设置
- 管理后台模块化：学生、动态、评论、私信、举报、审计
- 审计日志、CSV 导出、日报与趋势
- 意见反馈闭环与公告管理
- 登录协议勾选、用户协议、隐私政策
- 异常 IP 登录站内提醒、单设备会话互踢与被踢提示
- CampusLink 视觉改版：腾讯蓝 `#0052D9` 主色与配套深色主题、四组双色渐变侧栏入口方牌、话题标签低饱和彩底、侧栏「兴趣圈子」分组（兴趣标签聚合 + 线性图标直达标签筛选）
- 视觉规范重做：Manrope 自托管、字号/间距/圆角/动效全部落在统一刻度、卡片改为边框分层、按压反馈与 tabular-nums
- 页面背景层重构：极光兜底 + 视频层 + 玻璃雾罩，卡片浮在雾罩之上；弱设备与省流量模式自动降级
- 玻璃拟态组件：hero 卡、主区侧栏、统计卡与公告切角块分层使用不同模糊半径
- 登录页文字地球：ThreeUI「Text Path Studies」的 2D canvas 移植，字符随球自转并随主题切换墨色
- 站点标志「光圈」：SVG 矢量一套源导出 favicon / apple-touch-icon / PWA 图标
- 交付细节：自定义 404 页、OG/Twitter 分享卡、品牌色 favicon、页脚隐私政策与用户协议入口
- 页码跳转、移动端适配、随机兴趣标签补齐
- PHPUnit、集成测试、Playwright E2E、GitHub Actions CI
- PHPStan（level 2）静态分析与 PHP CS Fixer 风格检查接入 CI
- 自动化安全回归测试：XSS、CSRF、上传、路径穿越、SQL 注入、响应头
- 高频表性能索引迁移
- 管理员 TOTP 二次验证
- SSE 实时通知（失败自动回退轮询）
- 上传图片多尺寸缩略图、真实性校验与重编码
- 健康检查接口与部署探活
- 公网 HTTPS 演示环境
- API、OpenAPI、安全、部署、架构与路线图文档
