# 安全设计说明

本文档描述校园圈子在认证、输入输出、上传、限流、数据保护与审计方面的安全设计与运营约定。

## 1. 认证与会话

- 学生密码使用 bcrypt 哈希存储，管理员初始密码首次登录后强制修改。
- Session 启用 strict mode、HttpOnly、SameSite，HTTPS 下启用 Secure。
- 管理员角色分为超级管理员与运营管理员，学生实名审核、审计日志、学生导出仅超级管理员可访问。
- 学生端和管理员端使用独立会话状态，切换身份时旋转 Session 并生成新的活动会话令牌。
- 支持多标签页会话隔离，使用 `tab` 参数区分不同标签页会话。
- CSRF：所有写操作表单均携带随机 Token，服务端统一校验。

## 2. 输入输出安全

- 所有 SQL 使用 MySQLi 预处理语句或白名单拼接，禁止直接拼接用户输入。
- 输出统一经过 `h()` HTML 转义，防止存储型 XSS。
- 私信、评论、动态、反馈等文本均经过敏感词过滤。
- 用户名、手机号、邮箱、QQ、学号等字段在注册与资料修改时执行格式与长度校验。

## 3. 文件上传

- 仅允许 JPEG/PNG/GIF，通过 `getimagesize()` 校验真实图片类型。
- 上传后重新编码并清理 EXIF 元数据，限制尺寸与大小。
- 文件保存到独立上传目录，访问通过统一 `assetUrl()` 处理。
- 删除动态、反馈、账号时同步清理对应上传文件。

## 4. 登录限流与风控

- 登录、注册、找回密码均记录尝试日志。
- 登录限流：同一 IP 15 分钟内失败 20 次，或同一账号失败 10 次，则临时锁定 15 分钟。
- 所有登录表单均要求算术验证码，验证码一次性使用。
- 动态、评论、私信、举报等高频操作使用独立动作限流。

## 5. 数据保护与隐私

- 密码、学生证照片、联系方式等敏感信息仅用于实名审核与账号安全。
- 学生证照片不对其他学生展示，管理员访问记录写入审计日志。
- 隐私政策已覆盖信息收集、使用、存储、共享、用户权利与未成年人保护。
- 账号注销后删除或匿名化可删除数据，审计所需记录依法保留。

## 6. 审计

- 管理员审核、删除、举报处理、改密等关键操作写入 `audit_log`。
- 管理员后台提供审计日志分页查看与 CSV 导出。
- 管理员删除动态、评论、私信时保存回滚快照，可在审计日志中恢复。
- 私信审计可检索并删除违规私信，删除动作同步记录审计。

## 7. 安全事件响应流程

1. 发现疑似安全事件后立即停止相关入口并保留现场日志。
2. 通过管理后台审计日志、数据库备份和访问日志定位影响范围。
3. 修复漏洞并部署补丁，清理被入侵账号或恶意内容。
4. 按《隐私政策》和适用法规通知受影响用户与监管方。
5. 复盘事件根因，补充自动化测试和监控规则。

## 8. 自动化验证

- PHPStan（level 2）静态分析覆盖 lib/。
- PHPUnit 单元测试覆盖核心辅助函数。
- 集成测试覆盖注册、审核、动态、评论、私信、举报、反馈、找回密码等主链路。
- Playwright E2E 覆盖登录、移动端溢出、管理员角色切换等关键流程。
- GitHub Actions 在 CI 中执行语法检查、PHPUnit、集成测试与 E2E。
- Playwright 安全用例覆盖登录页安全响应头与匿名 API 返回 JSON 401。
- 独立安全回归测试 tests/security.php 覆盖 XSS 转义、CSRF、上传文件真实性、路径穿越与资源访问限制。
- 集成测试覆盖 SQL 注入用户名/搜索关键字、越权删除与编辑、拉黑后的私信/关注限制与登录限流。
